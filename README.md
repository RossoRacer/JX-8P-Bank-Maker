# JX-8P Bank Maker

Drag single patches from JX-8P/JX-10/MKS-70, groups of patches or whole banks (up to 32 patches - JX-8P size only) into the numbered slots. When filled you can save it as a JX-8P bank.

## 📱 Features
- Feature 1 - Drag and Drop interface.

## 🛠 Tech Stack
- **Language:** Swift / SwiftUI / UIKit
- **Architecture:** MVVM / MVC
- **Tools:** Xcode 16+
